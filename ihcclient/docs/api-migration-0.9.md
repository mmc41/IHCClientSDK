# Migrating to the 0.9 controller API

This note maps every change the 0.9 controller-I/O corrections make to `ihcclient`'s public surface: each
removed or changed row of `PublicAPI.Shipped.txt` or `PublicAPI.Unshipped.txt`, and each public member whose
behaviour changed while its signature stayed (result meaning, unit, offset, thrown exception).

As in 0.8, the SDK is an unpublished beta, so members change in place with no `[Obsolete]` forwarder and no
staged deprecation release. That makes a change *permitted*, not compatible: a caller that relied on the old
behaviour must act as the rows below say.

What the boundary is, and why, is [the API contract](api-contract.md). This note is the delta.

## 1. Behaviour changes

| Member | Was | Now | Action |
| --- | --- | --- | --- |
| `IUserManagerService.GetUsers` and `IAuthenticationService.Authenticate`: `IhcUser.Group` | A user-group key other than the two the SDK knows threw: `GetUsers` failed the whole list, and `Authenticate` ended a login the controller had granted and raised `LOGIN_UNKNOWN_ERROR`. | The key reads as `IhcUserGroup.None` with an `UnrecognizedUserGroup` span warning naming it; the rest of the list maps and the login completes. Writing `None` is still refused. | Treat `None` on a read as "no group or an unknown one"; read the span warning for the key. |
| `ITimeManagerService.SetSettings(TimeManagerSettings)` validation | Any offset, interval and server name went out. | `ArgumentException` before sending for a `GmtOffsetInHours` outside -12 to +14, and, with `SynchroniseTimeAgainstServer` on, a `SyncIntervalInHours` under 1 or a blank `ServerName`: what IHC Administrator refuses. `TimeManagerSettings` now implements `IValidatableObject`. | Correct such settings before writing them; with synchronisation off the interval and server are not checked. |
| `IConfigurationService.SetEmailControlSettings` and `TestSettingsNow` validation | A `ServerPortNumber` of 0 and a negative `PollInterval` went out. | Both are refused with `ArgumentException` before sending (port 1-65535, poll interval at least 0), as IHC Administrator refuses them. | Correct such settings before writing or testing them. |
| `ISmsModemService.SetSmsModemSettings` validation | The settings were only null-checked, so any `PowerdownNumber` (now `RecipientSlots`) went out. | A `RecipientSlots` mask that is set but is not 30 characters of `0` and `1`, the recipient-slot mask IHC Administrator builds, is refused with `ArgumentException` before sending; `null` still sends none. The 60-character limit of the two texts stays documentation. | Pass a 30-slot mask, such as one read back from `GetSmsModemSettings`. |
| `IResourceInteractionService.SetResourceValue`/`SetResourceValues` and `IOpenAPIService.SetValues` validation | Any weekday, scene dimmer percentage and ramp went out, and a value addressed to resource id 0. | `ArgumentException` before sending, from both write mappers alike, for a weekday outside 0-6, a scene dimmer percentage outside 0-100, a ramp over 3,600,000 ms and resource id 0: what the vendor editors refuse, and the `.vis` null reference no resource is allocated. | Keep such values within the documented ranges and address a real resource. |
| INT and DOUBLE `ResourceValue` reads and writes (`IResourceInteractionService`, `IOpenAPIService`) | The range the controller sent with an INT or DOUBLE value was dropped, and every write sent 0 as both bounds. | The range is kept on the value as `UnionValue.IntMinimum`/`IntMaximum` and `DoubleMinimum`/`DoubleMaximum` and written back with it, as IHC Visual writes a value back with its range; a value without bounds still sends 0/0, and a 0/0 range reads as none. Because `UnionValue` compares by field, a value read with a range no longer equals one built without it. | Compare `IntValue`/`DoubleValue` where only the value matters, or copy the bounds from the read value. |
| INT and DOUBLE resource writes (`IResourceInteractionService.SetResourceValue`/`SetResourceValues`, `IOpenAPIService.SetValues`) | Any value went out whatever its range. | A value outside the `IntMinimum`/`IntMaximum` or `DoubleMinimum`/`DoubleMaximum` it carries is refused with `ArgumentException` before sending, by both mappers alike, as ServiceView refuses one outside the range it was given; a value carrying no range is not checked. | Keep a value read with a range inside it, or clear the bounds to write without one. |
| `IControllerService.WaitForControllerStateChange(ControllerState, int)` | `ControllerState.Unknown` as `waitState` threw `ArgumentException`. | `Unknown` is sent as a nil state, as IHC Administrator sends it when it has read none, so a caller that read `Unknown` can keep polling. | Drop any substitute state invented to avoid the exception. |
| `TimeManagerSettings.TimeAndDateInUTC` (read by `ITimeManagerService.GetSettings`, written by `SetSettings`) | The UTC clock face was read and written at +01:00: a read was one hour early, and a correct instant written set the controller's clock one hour ahead. | Read and written at offset 0: a read is the controller's UTC clock, equal to `SystemInfo.Realtimeclock`, and a write sends the instant's UTC clock face. A value read and written back is unchanged. | Remove any one-hour correction applied around these calls. |
| `ITimeManagerService.SetSettings(TimeManagerSettings)` | `true` for result code 1 and `false` for any other code or none, so a refused write (1, the time could not be set) read as success and a successful one (0) as refused. | `true` for code 0, the vendor's success; `false` for any other code, 1 (the time could not be set) and 2 (the calendar is not available) among them. A reply carrying no code throws `InvalidOperationException`: the settings were sent and their fate is unknown. | Invert any handling that worked around the old reading; catch `InvalidOperationException` where an unacknowledged write matters. |
| `TimeManagerSettings.ServerName` (written by `ITimeManagerService.SetSettings`) | `[StringLength(20)]` refused a longer name with `ArgumentException`, so settings read from a controller using the vendor's 24-character default could not be written back. | No length limit: the WSDL declares an unrestricted string, and the Administrator's 20 columns are only a display width. | None; a name that was refused is now sent. |
| `EmailControlSettings` and `SMTPSettings` strings (written by `SetEmailControlSettings` and `SetSMTPSettings`) | `[StringLength]` maximums of 10 or 20 characters (IHC Administrator's display widths) refused longer values with `ArgumentException`, e.g. the 21-character `smtp-mail.outlook.com` or a POP3 user name written as a full mailbox address. | No length limit; the port ranges stay. | None; a value that was refused is now sent. |
| `IhcUser` strings (written by `IUserManagerService.AddUser` and `UpdateUser`) | `[StringLength]` maximums of 15 to 25 characters (IHC Administrator's display widths) refused longer values with `ArgumentException`, e.g. the captured 20-character last name `test lastname edited`. | No length limit. A user name and a non-blank password are still required (the empty-password refusal is SDK policy), the redacted password and the group `None` are still refused. | None; a value that was refused is now sent. |
| `WLanSettings.Key` (written by `IConfigurationService.SetWLanSettings`) | `[StringLength(63)]` refused the raw 64-hex-digit WPA2 pre-shared key. | At most 63 characters, or exactly 64 hexadecimal digits; anything else is refused with `ArgumentException`. | None; a raw key that was refused is now sent. |
| `IConfigurationService.SetDNSServers(DNSServers)` | Each server went through `IPAddress.Parse`: a leading zero was octal (`192.168.001.010` sent as 192.168.1.8), `08.8.8.8` was refused with `FormatException`, and short, hexadecimal and single-number forms were widened into some address. | Only four dot-separated groups of one to three ASCII digits, each 0-255, read as decimal (`010` is ten). Every other text, including text that is no address, throws `ArgumentException` naming it. | Catch `ArgumentException` rather than `FormatException`; write servers in dotted-decimal form. |
| `ITimeManagerService.GetCurrentLocalTime()` | The local clock face was read at a fixed +01:00, so in summer time the instant was one hour late. | The face keeps its clock reading and takes the controller's current offset, the local clock less the UTC clock of `GetSettings` rounded to 15 minutes, read in the same call (`getCurrentLocalTime`, then `getSettings`). Without a usable UTC clock the offset stays +01:00 and the span carries an `AssumedUtcOffset` warning. `IOpenAPIService.GetTime` keeps +01:00: the OpenAPI has no UTC clock. | Drop any summer-time correction; read `Offset` for the controller's current offset. |
| `IResourceInteractionService.GetLoggedData(int)` / `LoggedData.Timestamp` | The stamp was read as seconds since 1970, so every sample logged after early 1978 threw `ArgumentOutOfRangeException`, and an earlier one read a thousandfold off. | Read as milliseconds since 1970 UTC, as ServiceView reads it; a stamp no date can represent throws `InvalidOperationException` naming the value. | None, unless a caller multiplied or caught around the old reading. |
| Every string member read from a controller reply, e.g. `IhcUser.Email`, `Phone` and `Project`, and `EmailControlSettings.ServerAddress` (formerly `ServerIpAddress`), `Pop3Username`, `Pop3Password` and `EmailAddress` | An element the controller sent as `xsi:nil="true"` read as the text inside it: an empty string, or `"\n"` for the captured form with a line break, which a read-modify-write then sent back. | A nil string element reads as `null`. Array items and members of other types are read as before, so no array changes its length. | Treat `null` as unset; drop any trimming of a lone `"\n"`. |
| `IAirlinkManagementService.GetDevicesRunningOutOfBattery()` | A controller with no low-battery device answers `[-1]`, which was returned as is: one phantom device id per poll. | That lone `-1` reads as an empty list; real ids are returned as sent. | Drop any filtering of `-1`. |
| `IControllerService.SetS0FiscalYearStart(sbyte month, sbyte day)` | `month` was sent as the operation's first part and `day` as its second, so the controller, which reads the first as the day of the month, swapped them; the docs told callers to pass the day as `month` to compensate. | Each parameter means what its name says, and `day` is sent first, `month` second. | A caller that followed the old docs and passed the day as `month` now swaps its arguments back. |
| `IConfigurationService.GetDNSServers()`, `IOpenAPIService.WaitForEvents(int)`, `IOpenAPIService.GetDatalineInputIDs()`, `IOpenAPIService.GetDatalineOutputIDs()` | A nil list item, the form a 3.3.44 controller answers an empty list in, threw `NullReferenceException`. | A nil item is skipped: the lone-nil list reads as no servers, no events or no ids, and a nil item beside real ones is dropped and counted in a span warning. | None. |
| `IOpenAPIService.GetValues(IReadOnlyList<int>)` with no ids | A reply of one nil item, a controller's empty-list form, threw `InvalidOperationException` for 1 value against 0 ids. | Reads as empty. Every request for ids keeps the positional checks: a count mismatch or a nil entry is still refused. | None. |
| Every controller call (the SOAP transport under all services) | A SOAP fault was never read: with HTTP 500 the call threw a bare `HttpRequestException`, with HTTP 200 its empty message read as nothing answered or failed later; a login answered with a fault on HTTP 200 also cleared the stored cookie. | A fault raises `ErrorWithCodeException` with `Errors.CONTROLLER_LOGON_FAILED` for `Logon Failed` and `Errors.CONTROLLER_SOAP_FAULT` otherwise, the message carrying `faultcode` and `faultstring`, and runs no success side effect. A non-success status without a fault still throws `HttpRequestException`. | Catch `ErrorWithCodeException` by these codes where `HttpRequestException` was caught for a fault; log in again on `CONTROLLER_LOGON_FAILED`. |
| `IControllerService.StoreProject(ProjectFile)` | Each of its three state waits sent the state it EXPECTED as one 10-second long poll and failed on any other answer; a failed first wait skipped the change-mode exit. | Each wait reads the state first and is over when it is already reached; otherwise it polls with the state it last observed until the expected state or a 10-second deadline. Every step after entering change mode, the first wait included, is followed by an exit attempt on failure. The wire sequence changes accordingly: a `getState` precedes each wait, and a `waitForControllerStateChange` is sent only when that read lags. | None for a caller of the method; a test that pinned the old wire sequence follows the new one. |
| `IControllerService.GetProject()` | A gzip stream cut short decoded to the part that arrived, which was returned as the project with no error. | `InvalidDataException` when the file's data is not one complete gzip stream, one ending in the trailer that states its decoded length. | Download again; a project returned is whole. |
| `AdminAppService.Store`: a model without `MutableAdminModel.Users` | A model without `Users`, as a file lacking it or holding `null` loads, was stored as no accounts: every account on the controller was removed. | `ArgumentException` before the controller is contacted. `LoadFromJson` still loads such a file, to be read or completed. An empty list is still applied as the whole account list. | Keep the `Users` list in a file to be stored; to leave the accounts as they are, keep the list `GetModel` returned. |

## 2. Changed members

| Member | Was | Now | Action |
| --- | --- | --- | --- |
| `IControllerService.GetIHCProjectSegment` / `ControllerService.GetIHCProjectSegment` | `(int index, int major, int minor) -> Task<ProjectFile?>`: each segment gzip-decoded on its own into text, which fails for every segment after the first, since a controller's segments are slices of one gzip stream; `null` for a reply with no file. | `(int index, int projectMajorRevision, int projectMinorRevision) -> Task<ProjectSegment>`: the slice's raw bytes as the controller sent them, as `IOpenAPIService.GetIHCProjectSegment` returns them; data empty for a reply with no file. | Join the segments' `Data` in index order and decompress once (ISO-8859-1 text), or download whole with `GetProject`. Rename named arguments `major`/`minor`. |
| `IResourceInteractionService` / `ResourceInteractionService`: `GetInitialValue`, `GetInitialValues`, `GetResourceType`, `GetRuntimeValue`, `GetRuntimeValues` | Resource-id parameters named `initialValue`, `initialValues`, `resourceID` and `resourceIDs`. | `resourceId` and `resourceIds`, one spelling across the interface; the calls are unchanged. | Rename named arguments; positional calls are unaffected. |
| `IResourceInteractionService` / `ResourceInteractionService`: `GetSceneGroupResourceIdAndPositions`, `GetScenePositionsForSceneValueResource` | Parameters named after their methods: `sceneGroupResourceIdAndPositions`, `scenePositionsForSceneValueResource`. | `sceneGroupResourceId` and `sceneMemberResourceId`, after the id each takes; the calls are unchanged. | Rename named arguments; positional calls are unaffected. |
| Long polls: `IResourceInteractionService.WaitForResourceValueChanges` and `GetResourceValueChanges`, `IOpenAPIService.GetResourceValueChanges` and `WaitForEvents`, `IAirlinkManagementService.WaitForDeviceDetected` and `WaitForDeviceTestResult`, `ILedDimmerManagementService.WaitForDeviceDetected`, `IControllerService.WaitForControllerStateChange` (and their classes) | The hold was named five ways: `timeout_seconds`, `timeout_between_waits_in_seconds`, `timeoutSeconds`, `waitSec`, `timeout`; the second misdescribed it as a pause between waits. | `holdSeconds` on all eight, the longest time the controller holds each call; the calls and defaults are unchanged. | Rename named arguments; positional calls are unaffected. |
| `IResourceInteractionService.DisableInitialValueNotifactions` / `DisableRuntimeValueNotifactions` (and the class) | Named with the vendor's misspelling of the wire operations. | `DisableInitialValueNotifications` / `DisableRuntimeValueNotifications`; the wire operations keep the vendor's spelling. | Rename the calls. |
| `ResourceValue.UnionValue.DateTime` | A `DateTimeOffset?` member the SDK neither filled nor read. | Removed; a DATE value is carried in `UnionValue.DateValue`, as it always was. | Use `DateValue`; anything set in `DateTime` was never sent. |
| `EmailControlSettings.ServerIpAddress` | Named for an IP address, though it holds a host name or an address. | `EmailControlSettings.ServerAddress`; the wire element keeps `serverIPAddress`, and the admin-model JSON file keeps the key `ServerIpAddress`, so saved files load either way. | Rename uses of the property; saved admin-model files need no change. |
| `SmsModemSettings.PowerdownNumber` | Named after the wire element, though it holds no phone number. | `SmsModemSettings.RecipientSlots`, the 30-slot recipient mask; the wire element keeps its name `powerdownNumber`. | Rename uses of the property. |
| `ResourceValue.ToogleBool(ResourceValue)` | Misspelt. | `ResourceValue.ToggleBool(ResourceValue)`, unchanged otherwise. | Rename the calls. |
| `IOpenAPIService.GetIHCProjectSegment` / `OpenAPIService.GetIHCProjectSegment` | `(int index, int majorVersion, int minorVersion)`. | `(int index, int projectMajorRevision, int projectMinorRevision)`, the names `IControllerService.GetIHCProjectSegment` takes, after the `ProjectInfo` members they are read from; the call is unchanged. | Rename named arguments `majorVersion`/`minorVersion`; positional calls are unaffected. |
| `IControllerService.StoreIHCProjectSegment` / `ControllerService.StoreIHCProjectSegment` | `(ProjectFile segment, int index, int major) -> Task<bool>`: each segment's text gzip-compressed on its own, a gzip member per segment where a controller expects slices of one gzip stream; the third argument named as a version. | `(ProjectSegment segment, int index, int segmentCount) -> Task<bool>`: the slice's bytes sent unchanged, under its `Filename` (`temp.vis` when it has none), with the upload's segment count as the third argument, the same in every call. | Gzip the whole project's ISO-8859-1 text once, cut it at `GetIHCProjectSegmentationSize()` bytes and send each slice with its index and the slice count; or send it whole with `StoreProject`. |

| `IConfigurationService.SetEmailControlSettings` / `ConfigurationService.SetEmailControlSettings` | `(EmailControlSettings settings) -> Task`: the controller's acceptance flag was discarded, so a declined write completed like an accepted one. | `(EmailControlSettings settings) -> Task<bool>`: `true` accepted, `false` declined; a reply with no flag throws `InvalidOperationException`, the outcome being unknown. `AdminAppService.Store` fails with `InvalidOperationException` when the settings are declined, rather than report them applied. | Read the result: on `false` the settings were not applied. A caller of `AdminAppService.Store` handles the new failure. |
| `IControllerService.ResetS0Values` / `ControllerService.ResetS0Values` | `() -> Task`: the operation's five period flags all went out nil, so which figures were reset was not known. | `(bool hour, bool day, bool week, bool month, bool year) -> Task`: the flags in wire order, as IHC ServiceView sends them; no parameterless overload. | Pass the periods to reset; ServiceView's default ticks all five (`true, true, true, true, true`). |
| `ITimeManagerService.GetTimeFromServer` / `TimeManagerService.GetTimeFromServer` | `() -> Task<TimeServerConnectionResult?>`: the server to test went out nil, so which server the controller asked was not known. | `(string serverName) -> Task<TimeServerConnectionResult?>`: the host name or dotted IPv4 address to test, sent as given; `null` throws `ArgumentNullException`, empty or whitespace `ArgumentException`, before anything is sent. | Pass the server to test, e.g. `TimeManagerSettings.ServerName`. |
| `IConfigurationService.SetNetworkSettings` / `ConfigurationService.SetNetworkSettings` | `(NetworkSettings settings) -> Task`: the acceptance flag was discarded, so a declined write completed like an accepted one, and the captured outcome of an address change, a cut connection, surfaced as a bare `HttpRequestException`. | `(NetworkSettings settings) -> Task<bool>`: `true` accepted, `false` declined; no flag throws `InvalidOperationException`; a transport failure before any answer throws `ErrorWithCodeException` with `Errors.CONTROLLER_WRITE_UNCONFIRMED`, the transport's error inside, while an HTTP error status, the controller's answer, still throws `HttpRequestException`. `AdminAppService.Store` fails on a declined write and lets the unconfirmed one through; `ihc_admin` reports it as an unknown remote state. | Read the result; on `CONTROLLER_WRITE_UNCONFIRMED` reconnect (at the new address if one was set) and read the settings back before retrying. |
| `IConfigurationService.GetUserLog` / `ConfigurationService.GetUserLog` | `(string lang = "da") -> Task<IReadOnlyList<string>>`: every read sent an empty cursor and the reply's file name, the next cursor, was dropped. | `(string lang = "da", string cursor = "") -> Task<UserLogFileText>`: the cursor is sent, and the reply's file name comes back as `FileName` beside the lines. `lang` stays first, so a positional `GetUserLog("en")` still means the language. | Read the lines from `.Lines`; to follow the log, pass the previous read's `FileName` as `cursor`. |
| `UserLogFileText.Content` | `string?`, on a record nothing returned. | Removed; the record's lines are `Lines` (`IReadOnlyList<string>`, never null), and two reads compare equal when their cursors and lines are. | Use `Lines`. |
| `ILedDimmerManagementService.StartFirmwareUpgrade` / `LedDimmerManagementService.StartFirmwareUpgrade` | `(string serialNumber)`: `null`, the controller's "every dimmer", worked only against the declared contract and drew a nullable warning. | `(string? serialNumber)`: `null` upgrades every dimmer in one call, sent as a nil part. | None; a caller passing a serial is unaffected, and one passing `null` loses its warning. |
| `IConfigurationService.TestSettingsNow` / `ConfigurationService.TestSettingsNow` | `() -> Task`: sent a nil settings record, so what the controller tested was unknown, and discarded the status it answered. | `(EmailControlSettings settings) -> Task<EmailControlConnectionStatus?>`: the settings to test go out, validated as `SetEmailControlSettings` validates them, and the four status flags come back; `null` when the reply carries none. | Pass the POP3 settings to test, such as unsaved ones from a dialog, and read the returned status. |
| `IConfigurationService.TestSendMessage` / `ConfigurationService.TestSendMessage` | `(string recipient, string subject, string message) -> Task<bool>`: posted the four-part `testSendMessage1` overload, which no vendor client calls, with subject and body as loose strings and the message's own fields empty, under a SOAPAction the WSDL does not bind; `false` covered failure and a missing result alike. | `(SMTPSettings smtp, string recipient, string subject, string message) -> Task<NotificationSendResult?>`: the six-part `testSendMessage` IHC Administrator sends, the message carrying subject, body, recipient and the sender `LK IHC® controller<user>`, the loose parts the SMTP account to test; `smtp` is validated as `SetSMTPSettings` validates it; the eight outcome flags come back, `null` when the reply carries none. | Pass the SMTP account to test, such as unsaved settings or `GetSMTPSettings()`'s, and read `AttemptSucceeded` or the failure flag. |
| `IConfigurationService.SetWLanSettings` / `ConfigurationService.SetWLanSettings` | `(WLanSettings settings) -> Task`: the reply's flag was discarded. | `(WLanSettings settings) -> Task<bool?>`: the flag as the controller sent it, `null` when absent. Its meaning is not established and IHC Administrator ignores it, so neither `false` nor `null` throws or is reported as a refusal; `AdminAppService.Store` ignores it too. | None required; read the flag only as the controller's raw answer. |

## 3. Additions

| Member | What it does |
| --- | --- |
| `SMTPSettings.SendLEDDimmerErrorNotification` | The controller's LED Dimmer error-mail switch, read by `IConfigurationService.GetSMTPSettings` and written by `SetSMTPSettings`; before, the SDK neither read nor sent it, and what a write did to it was unknown. A caller that writes settings read before this version, or built without the switch, now sends it as `false`. |
| `EmailControlConnectionStatus` | The outcome `IConfigurationService.TestSettingsNow` returns: `LastConnectionAttemptSucceeded`, `AttemptFailedDueToAuthentication`, `AttemptFailedDueToNetworkProblems` and `AttemptFailedDueToInvalidSettings`, the controller's four flags as sent. |
| `NotificationSendResult` | The outcome `IConfigurationService.TestSendMessage` returns: `AttemptSucceeded` and seven failure flags (authentication, network, invalid settings, internal errors, connect timeout, connection refused, I/O timeout), the controller's eight flags as sent, the two the wire misspells `attempFailed…` spelt correctly. |
| `ResourceValue.UnionValue.IntMinimum`, `IntMaximum`, `DoubleMinimum`, `DoubleMaximum` | The range an INT or DOUBLE value arrived with, `null` when the controller sent none (or 0/0); a write sends them, 0 for an absent bound. |
| `IControllerService.GetProjectInSegments()` / `ControllerService.GetProjectInSegments()` | Downloads the stored project through its segments, the way ServiceView does: `GetProjectInfo` for the identity, `GetIHCProjectNumberOfSegments`, every `GetIHCProjectSegment` slice joined in index order and decompressed once. Returns the project text `GetProject` returns, named as the controller names its segments (`unknown.bin` on 3.3.44); `null` with no project or no segment; `InvalidOperationException` when a segment carries no data or the joined slices do not decompress as one complete gzip stream. |
| `IControllerService.StoreProjectInSegments(ProjectFile)` / `ControllerService.StoreProjectInSegments(ProjectFile)` | Uploads a project in segments, the way IHC Visual sends one: the same checks, project change mode, state waits and exit-on-failure as `StoreProject`, and inside the mode `GetIHCProjectSegmentationSize`, then the project's ISO-8859-1 text gzipped once and cut into slices of that size (the last shorter, never empty), each sent with its index and the slice count. `true` when every slice is accepted; `false` when one is declined, after which none is sent; `InvalidOperationException` for a non-positive segmentation size or an unacknowledged slice. Like `StoreProject` it neither resets runtime values nor restarts the controller. |
