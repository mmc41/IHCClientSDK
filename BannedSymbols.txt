// Symbols banned at compile time across the repository. Applied by Directory.Build.targets to every
// project except the few that legitimately own or white-box the generated layer; those opt out with
// <UsesGeneratedSoapLayer>true</UsesGeneratedSoapLayer>, which makes each exception greppable.
//
// Format: one entry per line, "<documentation-comment ID>;<message shown in the error>".

// The generated SOAP layer is public because XmlSerializer binds only public types, not because it is
// meant to be consumed (ADR-003). Nothing outside the SDK may bind to it: a caller that does couples
// itself to positional WSDL artifacts that change whenever the vendor's WSDL does, and bypasses the
// anti-corruption layer the API services exist to provide. Use the Ihc.* service interfaces and the
// SDK models in Ihc.Soap's place. The ban is namespace-wide, so a SOAP service added later is covered
// on arrival without editing this file.
N:Ihc.Soap;Use the high-level Ihc service interfaces and SDK models instead of the generated SOAP layer.

// The SOAP ENVELOPE roots are public for the same reason the layer above is, and for no other: an
// XmlSerializer binds public types and fails at RUNTIME otherwise, which neither XmlAttributeOverrides nor a
// friend assembly lifts (ADR-003). So they carry the same consumer prohibition rather than the accessibility
// one they cannot have. Nothing outside the transport builds or reads an envelope: a caller that does is
// working at the wire's framing rather than at the SDK's models, which is precisely what the API-service tier
// exists to spare it. The exceptions opt out the same greppable way, with UsesGeneratedSoapLayer.
N:Ihc.Envelope;Call the Ihc service interfaces — an envelope is the transport's framing, not an SDK model.
