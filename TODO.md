- Move the `[Explicit]` tests that generate oracles out of the test projects into separate utilities, and delete any that no longer serve a purpose. NUnit runs an `[Explicit]` test whenever a `dotnet test --filter` matches it, so a broad filter can run a generator together with the gate that checks its output. All of them are in `safe_project_tests`. Deleting a generator never weakens its gate, which reads the committed file; what goes is the only sanctioned way to update that file when a change is intended, because each one is byte-compared or documented as generated and never hand-edited. The subtasks are independent: each owns its generators, the code only they use, and the docs and messages that name them. The two shared pieces, `ReportOracleHarness.WriteGeneratedInto` and the `CLAUDE.md` Testing bullet, are noted where they apply.
